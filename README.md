# 🌐 Personal Portfolio – Harshini Ananthan

Welcome to my personal portfolio website, a fully responsive and modern web application built using **Next.js**, **React**, and **Tailwind CSS**. This website serves as a digital profile to showcase my skills, projects, achievements, and contact information in a clean, professional, and accessible format.

## 🚀 Live Site

🔗 [Harshini Portfolio](https://harshini-a.web.app)

---

## 📌 Overview

This project is designed to highlight:

- ✅ A brief **personal introduction**
- 💡 A categorized **tech stack & skills section**
- 🧠 Details of **projects** I've built or contributed to
- 🎓 **Education and career timeline**
- 🏆 Notable **achievements and coding profiles**
- ✉️ A functional **contact form** interface
- 🔗 Clickable **social media links** and professional footer

## 💻 Local Development

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   # or
   pnpm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   # or
   pnpm dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🚀 Deployment

This project is configured to be deployed on **Firebase Hosting**.

Build and export the project:
```bash
npm run build
# or
pnpm build
```

Deploy to Firebase:
```bash
firebase deploy --only hosting
```
